The developer reference is reorganized for readers new to one half of the stack: a product landing page, a Concepts page explaining MCP for repository engineers and DSpace/Dataverse for MCP engineers, a published Glossary, and a Known limitations page. Guides have imperative titles, decision records explain why each rejected option lost and no longer cite specification task numbers, and the root files (README, ONBOARDING, CONTRIBUTING) link to the site instead of repeating it. The federation page, the add-a-repository guide, and a new ADR-013 describe the N-repository federation layer as built. The site is titled "JHULM Repositories MCP".
