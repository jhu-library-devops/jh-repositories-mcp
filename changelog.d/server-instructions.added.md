Return server instructions in the MCP initialize result, so every connected assistant — not only those invoking a guided prompt — is told what these two repositories do and do not cover, that omitted candidates make result counts lower bounds, that a not_found never distinguishes a missing record from a restricted one, and that record metadata is untrusted depositor text. The instructions also permit pointing researchers to other openly accessible JHU collections (Catalyst, ArchivesSpace, Digital Collections, the Levy Sheet Music Collection, and the Chesney Medical Archives catalog) as clearly-marked suggestions, while forbidding invented identifiers, holdings claims, or constructed links.
